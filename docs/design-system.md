# 视觉规范

本官网使用 frontend-design Skill，独立于业务系统。

## 设计与简报复核

白色页面、灰色结构、粮穗绿点缀。将“粮仓”抽象为几何仓体与一根穗轴，形成自己的品牌标识。记忆点集中在大字号中文标题和高保真分层粮温监测界面，不使用装饰网格、发光、玻璃或大面积深色。

最初考虑三列功能卡片，复核后舍弃：核心能力通过可切换的真实界面、两段交错图文、通讯结构图与导出格式排版表达，避免把现场工作切成九张相同卡片。

## Tokens

- Canvas #ffffff；Surface #f6f7f6；Ink #202521；Muted #69716b；Line #e4e8e4；Brand #38664d。
- 中英文统一采用自托管 Noto Sans SC 可变字体（SIL OFL 1.1），400 正文、500 标题与按钮、600 重点标签。字体按当前官网文本裁剪为约 138KB WOFF2，预加载并使用 swap；未包含的新字符回退 PingFang SC / Noto Sans CJK SC / Microsoft YaHei。主标题 -0.035em、章节 -0.03em 字距；正文保持 1.8 行高，单段约 30 中文字宽。参考 Claude Code 的轻字重与自然字距，保留本站无衬线方向与现有布局。
- 字阶：桌面主标题 70px（大屏 84px），手机 43px；章节 44px/32px；正文 16px；辅助 13px。
- 内容宽 1160px；页面边距桌面 40px / 手机 22px；章节间距 120px / 76px。
- 按钮 8px 圆角；产品窗口 14px；大展示背景 22px。避免全站同一种卡片容器。
- 小边框提供结构；仅产品展示使用清晰的柔和投影。

## 交互与可访问性

首屏仅一次 500ms 轻盈入场；其余动效响应用户切换、打开菜单和图片。降低动态效果偏好关闭全部入场与平滑滚动。可见焦点、跳过导航、语义链接和按钮、图片替代文本、对话框 Escape 关闭及焦点归还。截图放大提供键盘可用的按钮；移动端保持整张截图，并允许放大查看。

## 首屏产品展示调整

采用独立 MonitoringPreview 组件，白色软件主窗口与浅灰侧栏，分层温度表作为主内容。左下曲线卡、右上采集记录卡与右下导出提示形成有限层次。没有三维模型、玻璃或渐变背景。样本数据单独管理，演示曲线明确注明演示。手机端隐藏侧栏和采集浮卡，曲线与导出提示移至主窗口下方，避免遮挡温度表。
